搞门户 V1.05
网站、账号，一点就到。

安装
打开GaoMenHu-1.05.dmg，把「搞门户.app」拖入 Applications。
本机也可通过 Scripts/install.sh 自动安装。
升级会替换旧版 App，保留用户配置、恢复快照与钥匙串密码。

启动台与布局
单击网站图标：使用默认浏览器打开。
右键网站：选择允许的其他浏览器、切换账号、编辑或移除入口。
设置 → 模块设置 → 启动台：选择紧凑／宽松布局，以及小（60）、标准（76）、大（92）三档图标。
紧凑布局减少留白；长网站名称最多显示两行。
拖动图标：调整顺序。
把网站拖到另一个网站中央，稍作停留后松手：创建文件夹。
把网站拖进文件夹：加入文件夹。
打开文件夹，点击名称：重命名。
拖到文件夹下方「移回首页」区域：移出文件夹。

搜索后直接打开
Control + Option + Space：随时唤起搞门户并聚焦搜索。
输入网站名称、网址、中文拼音、拼音首字母或自定义简称。
用 ↑／↓ 选择搜索结果，按回车打开；也可以直接单击结果。
右键网站 → 编辑网站与账号 → 自定义简称：可用空格或逗号分隔多个简称。
例如给 Google 学术设置“学术 scholar”，以后输入“学术”即可查找；多音字可用简称补充。
搜索也支持账号名称和用户名，不会搜索或显示密码。

翻页
双指在触控板上横向滑动：上一页或下一页。
也可使用底部箭头、页码圆点、方向键及 Page Up / Page Down；Home / End 跳到首页或末页。
方向键在图标上有焦点时先移动焦点，到边界再翻页。
拖动图标到启动台左／右边缘，停留约 0.6 秒可翻一页；移开边缘后再次靠近可继续翻页。
拖动到页码圆点也可跨页整理。
搜索、编辑文字和弹窗中的操作不会触发启动台手势翻页。

批量整理与撤销
点击搜索栏右侧“整理”，或右键网站 → 选择并批量整理。
单击网站进行多选；“全选当前页”会选中本页网站，文件夹会选中其中的网站。
“移入文件夹”：选择已有文件夹、新建文件夹或启动台首页。
“默认浏览器”：只列出所有选中网站共同允许、且已经安装的浏览器。
“移除”：只移除入口，网站与账号仍保留；点击“完成”结束整理。
点击“撤销”或按 Command + Z，可撤销拖动、文件夹整理、入口移除和批量默认浏览器修改。
撤销不会回滚账号或密码；在文字输入框中，Command + Z 保持文字编辑的撤销行为。
重新打开 App 后如需恢复历史排列，可使用本地自动快照。

浏览器
每个网站必须选择至少一个允许的浏览器。
点击图标始终使用设置的浏览器，不会自动切换到未允许的浏览器。
支持 Chrome、Edge、Safari、Firefox 启动；自动填充支持 Chrome 和 Edge。
连接多个浏览器个人资料时，请在网站编辑页明确选择资料。
指定资料尚未连接时会提示重新连接，避免打开错误的账号环境。
没有账号需要填充、未指定资料且助手未连接的普通网页，会直接交给指定浏览器打开。

自动填充与重新连接
安装搞门户助手：设置 → 模块设置 → 浏览器助手 → 管理扩展。
开启「开发者模式」，选择「加载已解压的扩展程序」。
扩展目录：/Applications/搞门户.app/Contents/Resources/BrowserExtension
打开助手弹窗，可以给当前浏览器个人资料命名。
添加网站账号后，Mac 身份验证通过才会为从搞门户启动的标签页填充。
搞门户会提示正在连接、等待登录表单、填充结果或失败原因。
填充不会点击登录，不会处理验证码或二次验证。
账号使用第三方登录、邮箱验证码或通行密钥时，请使用网站对应的登录流程。
若登录页和网站首页域名不同，请在账号中填写准确的「其他登录域名」。
只在 HTTPS 登录页面填充；密码修改及注册表单不填充。
助手断开时：设置 → 模块设置 → 浏览器助手 → 重新连接；也可在浏览器助手弹窗点“重新连接”。
V1.03 新增 alarms 权限，仅用于定时唤醒后台并恢复与搞门户的连接，不读取 Cookie 或浏览器密码库。
升级后若助手未出现新功能，请在扩展管理页重新加载搞门户助手，再打开助手弹窗。

从浏览器导入收藏栏
设置 → 模块设置 → 启动台 → 导入浏览器收藏。
选择 Edge 或 Chrome 的个人资料，查看网站数、文件夹数、重复数和目录名称，确认后导入。
导入范围是所选资料的收藏栏；新增网站默认使用来源浏览器。
多层文件夹会显示为路径名称，例如“研究 / 期刊”，网站在各文件夹中的相对顺序保留。
重复网址保留搞门户现有账号与浏览器设置；路径、查询参数不同的网址仍可分别保存。
此功能只读取收藏，不读取浏览器密码或 Cookie；导入前会保存本地快照。

浏览器中一键收藏到搞门户
在 Chrome 或 Edge 打开普通网页，再打开“搞门户助手”弹窗。
在“收藏当前网页”中选择首页或现有文件夹，点击“收藏到搞门户”。
网页标题、网址、当前浏览器与个人资料会一并保存。
已收藏的网址不会重复新增；此前移除的入口可以恢复，并保留原有设置。

网站图标
自动寻找网站提供的清晰图标，并优先使用较大尺寸。
过小图标不会强制放大；网站暂时不可达时保留原图标，没有原图时显示文字标识。
设置 → 模块设置 → 启动台 → 刷新网站图标：重新获取全部自动图标，保留手动设置的图标。
右键网站 → 重新获取清晰图标：只刷新这个网站。
右键网站 → 编辑网站与账号 → 更换图标：选择自己的图片。
在“调整图标”中拖动图片位置、调整缩放；“居中适应”可重置位置和大小。
点击“使用图标”后，再点击“保存网站”完成保存。
若要把手动图标恢复为网站自动图标，在编辑页点击“获取清晰图标”，再保存网站。

工作场景
点击侧栏“工作场景” → 创建工作场景。
填写名称，例如“写论文”，选择要一起打开的 1 至 20 个网站，保存场景。
点击“打开场景”，搞门户会依次打开网站，每个网站使用自己的默认浏览器、个人资料和默认账号。
需要填充已保存密码时，仍需完成 Mac 身份验证；有浏览器或资料配置问题时会提示处理。
可以编辑或删除场景；删除场景只删除组合，不删除其中的网站、账号或密码。

账号与数据
密码保存在 macOS 钥匙串，不写入网站配置、日志、剪贴板或网址。
解锁授权为 5 分钟；锁屏和睡眠后自动锁定。
移除网站入口：保留账号，可在账号库或设置 → 模块设置 → 查看已移除的网站中恢复。
删除账号：删除搞门户保存的账号及钥匙串密码。
日常模式不清理浏览器自身保存的密码或 Cookie。
网站配置：~/Library/Application Support/MenDao/library.json

备份、恢复与自动快照
设置窗口分为“模块设置、外观、数据”；Command + 逗号打开设置。
外观支持跟随系统、浅色和深色。侧栏切换启动台、工作场景和账号库。
设置 → 数据 → 完整资料：导出搞门户-完整资料.zip，包含当前网站、账号信息、图标、排列、场景、设置及最多 10 份恢复快照，不包含密码和浏览器 Cookie。
“从完整资料恢复”会先校验应用、版本和所有文件 SHA-256，再展示确认；备份不完整或校验失败时不会覆盖当前数据。
恢复前保留当前资料快照；导入和已有快照合计最多 10 份。外来账号需重新填写密码，本机账号继续保留现有钥匙串绑定。
菜单栏“数据”中也可直接导出、恢复或合并导入。
设置 → 数据 → 模块格式 → 导出模块备份：保存网站、账号名称和用户名、文件夹、排列、外观设置与工作场景，不包含密码。
“合并导入模块备份”：预览后新增网站及其文件夹；重复网址保留现有配置。
“恢复模块备份”：预览后恢复备份中的文件夹、排列和场景；备份未包含的现有网站保留为已移除入口，不删除账号。
现存本机账号继续使用当前账号信息和钥匙串绑定；外来账号需要重新填写密码。
批量整理、导入、恢复和场景编辑等操作前，会自动保存一份本地快照，最多保留最近 10 份。
“查看恢复快照” → 预览恢复 → 恢复布局，可以回到某次操作之前。
快照目录：~/Library/Application Support/MenDao/Snapshots
快照不包含密码，是用户的恢复数据，不是构建中间文件；升级、卸载旧版 App 或清理构建时应保留。

快捷键
Control + Option + Space：随时唤起并搜索
Command + N：添加网站
Command + F：搜索
Command + Z：撤销整理（输入框中撤销文字编辑）
Command + L：锁定账号库
Command + Control + F：切换全屏
Command + Control + S：显示或隐藏侧栏
Command + 逗号：打开设置
Command + Q：退出
关闭窗口后搞门户继续在菜单栏运行，可随时唤起。

版本与更新
初始版本 V1.00，后续正式更新每次增加 0.01；当前版本 V1.05。
成功构建后 Release 只保留当前版本安装包。
升级替换旧版 App，保留用户配置、恢复快照与钥匙串密码。
所有构建中间文件在临时目录生成，构建完成自动删除。
