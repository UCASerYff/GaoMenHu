# 安装核验与失败处理

本说明适用于搞门户当前版本的程序换装。只处理 `cn.mendao.launcher`，不修改其他应用，也不创建安装、升级、迁移或回滚备份。

## 候选核验

`Scripts/install.py` 只使用 `Release/GaoMenHu-<版本>.dmg` 及同名 `.sha256`。安装前必须依次确认：

- DMG 实际 SHA-256 与校验文件一致。
- App 的 Bundle ID 为 `cn.mendao.launcher`，版本和 build 与 `VERSION` 一致。
- 主程序 `MenDao` 与桥接程序 `MenDaoBridge` 均通过严格签名校验。
- Team 为 `5G96498KGJ`，指定要求不含 cdhash 限制。
- 镜像展开和安装暂存均在创建 App 前进入 `.noindex` 容器。

## 安装边界

核验通过后，脚本正常请求旧应用退出，再次核对旧安装路径与 Bundle ID，随后只替换 `/Applications/搞门户.app`；旧名称 `/Applications/门道.app` 仅在身份相符时清理。不会复制旧程序、导出用户资料或生成回滚副本。

网站、下载、邮件、设置、附件及初始化证据继续留在原数据路径；原钥匙串服务及凭据不变。安装器不读取或上传这些业务内容。

## 失败处理

候选缺失、摘要不符、签名或身份异常、挂载或安装失败时停止并如实报告。失败不自动创建备份，也不以复制旧资料、重建空库或清理现用数据作为恢复手段。应先查明具体失败步骤，再处理本轮精确暂存路径。

安装完成后，必须在真实用户会话分别核对 Spotlight 和 LaunchServices：有效结果只指向 `/Applications/搞门户.app`。空结果、查询失败或脚本成功返回均不算唯一入口核验通过；不得全局重置索引或登记。
