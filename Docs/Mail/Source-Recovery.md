# 源码、发行包与现用资料

本说明区分搞门户的公开源码、正式发行包与本机现用资料。当前版本不创建或保留自动备份、升级快照、旧程序回滚副本或私人文件归档。

## 公开恢复来源

- 源码仓库 `https://github.com/UCASerYff/GaoMenHu` 提供 `Sources/`、`Scripts/`、`Tests/`、`VERSION`、公开说明与图标母版。
- GitHub Release 提供当前 `GaoMenHu-<版本>.dmg` 与对应 `.sha256`。下载后须核对 SHA-256，再按安装说明核验应用身份与签名。
- `Assets/AppIcon.png`、`Scripts/MakeIcon.swift` 和 `Scripts/make_icns.py` 可重建 ICNS；派生图标与临时构建产物不需要单独保存。

## 现用资料边界

邮箱资料、身份与关联平台、邮件缓存、附件、草稿、偏好设置、下载队列和网站资料不属于公开源码或发行包。它们继续留在原数据路径；缺失、损坏或无法读取时停止写入，不得当作空白覆盖。GitHub 克隆或下载 DMG 不包含这些资料，也不应用来覆盖本机业务数据。

密码、授权码、OAuth 令牌及私有客户端配置不得写入源码、公开日志、发行包或公开核验记录。钥匙串凭据继续由系统钥匙串保存，不导出或更改原服务绑定。

用户主动执行的网站 ZIP、JSON 与邮件资料导入导出仍可使用；这些操作不自动生成恢复前副本。安装或构建失败时停止并报告，不创建备份，也不以重建空资料作为恢复手段。

## 重建核验

干净克隆可在 Apple Silicon、macOS 14 或更高版本及相应开发工具下运行 `./Scripts/build.sh`。构建只生成当前 DMG 与校验文件，临时目录结束后清理。重建包的哈希可能受工具链、签名及打包元数据影响；源码版本、应用版本、build、签名和 Release 附件应分别核验。
