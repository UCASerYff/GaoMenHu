# 内置下载：迁移和恢复

搞门户的 HTTP/HTTPS 文件下载库由原搞下载迁入。来源必须先停止写入，并完整备份数据库及上一快照、独立初始化记录、交换包与账本、对应偏好证据、原目录授权与未完成片段。来源缺失但仍有初始化或历史依据时停写，不能导入空白。安装并不等于资料已迁入或已获原目录权限。

本轮迁移仅由协调流程显式执行，不在启动时自动取走旧数据。迁移持来源资料锁、逐项验证 schema/摘要和任务映射；目标提交有独立阶段证据。已验证提交中断时可按同一来源快照继续，尚未完成验证的中断保留恢复状态，不清空重建。重复迁移不会覆盖目标后来新增的任务。来源项目/应用的最终退役由协调方在所有消费方改指并验证后统一处理。

迁入后任务不会自动开始。请在下载中心重新选择原保存目录，系统授权由本人操作。目录身份相符后保留原grant UUID，未完成片段和已发布文件仍须核验；手动恢复任务时再检查强ETag和片段摘要。没有可靠资源校验器或版本改变时会从零下载，旧正式文件不覆盖。完成历史不重新下载。

应用退出前停止调度、同步并记录断点；重新打开由你恢复。睡眠、断网与权限失效可能中断，不能承诺后台或关机继续。取消不会删除已发布原件。清理临时文件只允许任务清单、目录FD和身份核验一致的自有文件，不能清空用户下载目录。

恢复时保留当前资料与备份，不拼接不同日期的库和独立证据，不将 previous 快照当自动回退。目录、资料、账本、附件、初始化或事务缺失/损坏/过新时维持保护；下载原件和钥匙串均不自动覆盖。网站“完整资料”导出仅覆盖网站模块，完整升级备份另包括下载队列、授权、设置、交换历史及相邻初始化记录；凭据仍留在原钥匙串。

外接设备验收不做（用户取消），不能把未接入外接存储算通过。当前只使用本机目录和公开系统能力；不导入浏览器Cookie，不绕过受限媒体或登录限制。
